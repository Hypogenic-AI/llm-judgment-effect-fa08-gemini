# Datasets for Experimentation

Note: Actual data files are located in the `code/` directory repositories but summarized here.

## 1. DialDefer Unified Benchmark
- **Location**: `code/DialDefer/dataset/benchmark_data/sampled_formatted/`
- **Source**: AdvisorQA, TruthfulQA, GPQA, etc.
- **Task**: Factual inquiry vs. Conversational judgment.

## 2. r/AIO (Am I Overreacting)
- **Location**: `code/DialDefer/dataset/aio/`
- **Source**: Reddit naturalistic conversations.
- **Task**: Interpersonal conflict judgment.

## 3. CausalT3 / CausalT5K
- **Location**: `code/CausalT5kBench/final_dataset/`
- **Source**: Causal reasoning vignettes across 10 domains.
- **Task**: Causal link verification under pressure.

## 4. CALM Bias Datasets
- **Location**: `code/LLM-Judge-Bias-Dataset/bias_datasets/`
- **Source**: Perturbed datasets for Authority, Verbosity, Sentiment biases.
- **Task**: Bias quantification in LLM judgments.
